THE GOLDEN LETTER
For Baby Julie, from James Traigo

Open the letter
Extract the entire ZIP first. Open julie-golden-love/index.html in your browser.
For VS Code Live Server, open the extracted julie-golden-love folder in VS Code,
right-click index.html and choose Open with Live Server.

Choose the song
An original instrumental called For Julie is included so the letter has music
the first time it opens. To use your copy of Keep Me by Novo Amor for everyone:
1. Rename your MP3 to music.mp3.
2. Replace the existing julie-golden-love/assets/music.mp3.
3. Reload your local site or redeploy the folder. Click Open Your Golden Letter.
The web player recognizes the replacement as Keep Me by Novo Amor.

To try another track for this visit, open Soundtrack, choose Choose my MP3,
and select the file. It plays from your device. Refreshing the page returns to
the bundled music. The Soundtrack menu also has play, pause, mute and seek.

Deploy to Vercel
Import a Git repository containing the extracted files. Set Root Directory
to the folder containing index.html. Select the Other framework preset,
leave the build command empty and use . for the output directory. Deploy.
After changing the music file, redeploy to include it in the hosted website.

Personalize
Edit index.html for the main and final letters. Edit js/messages.js for the
five chapter letters, quiz and ten reminders. The artwork is inline SVG and
CSS. The site runs without a build step, external pictures or font downloads.
